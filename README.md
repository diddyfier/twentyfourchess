# Grandmaster Chess

Playable single-file web chess game ready to host on GitHub Pages.

### Features
- Minimax AI engine (Easy, Medium, Hard)
- Web Audio synthesized sound effects
- Smooth piece slide animations
- Custom themes & chess clock timers

### Hosting Instructions
1. Upload `index.html` to your GitHub repository.
2. Go to **Settings -> Pages**.
3. Select **Branch: main** and Save.
